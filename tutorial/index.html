python-dpic / tutorial

DPI-C from scratch, then Python as a golden model

An incremental tutorial on the SystemVerilog Direct Programming Interface, measured on Verilator 5.052, ending with Python functions called as bit-exact reference models from a SystemVerilog testbench. Every step: tutorial text, exercises with hidden solutions, a self-grading quiz, a lab (lab/check.py) and a cheat sheet.

Part A — DPI-C

  1. 01First call

    import "DPI-C", pure, renaming, libm, how Verilator compiles and links C, the generated prototype header, extern "C".

  2. 02Data types

    The SV↔C type map, svBitVecVal/svLogicVecVal, wide vectors, directions, 2-state vs 4-state.

  3. 03State and handles

    Static vs per-instance state, chandle, C++ models behind a C ABI, lifetime and leaks.

  4. 04Arrays, structs, strings

    Fixed and open arrays, svOpenArrayHandle, packed arrays, struct layout, string ownership.

  5. 05Export and context

    Calling SV from C, context vs pure, scopes, time-consuming exported tasks.

  6. 06Golden model in C

    DUT + C reference + scoreboard, random stimulus, bug injection, cost per call.

Part B — Python

  1. 07Embedding Python

    The CPython C API from a DPI library: lifecycle, imports, refcounts, errors, the GIL, venvs.

  2. 08Python golden model

    zlib and numpy as reference models, wide ints, arrays without copies, batching, pysv / PyHDL-IF / cocotb.
