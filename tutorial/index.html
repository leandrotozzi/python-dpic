How to use it

Read a step, try the exercises before opening the solutions, take the quiz, then run its lab: cd tutorial/01_first_call/lab && python3 check.py. Every number in a guide is asserted there. The index on the left of each guide ticks off sections as you read them; this page shows that progress.
